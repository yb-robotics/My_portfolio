## 💻 Web App Setup & Installation

If you would like to run the interactive portfolio site locally, follow these steps:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/yb-robotics/My_portfolio.git
    cd My_portfolio
    ```

2.  **Install Dependencies:**
    ```bash
    npm install
    ```

3.  **Start Development Server:**
    ```bash
    npm run dev
    ```
    Open `http://localhost:3000` to view the interactive 3D and cinematic interface.

4.  **Create Production Build:**
    ```bash
    npm run build
    ```
    Builds the optimized Next.js app to the `.next/` directory.
